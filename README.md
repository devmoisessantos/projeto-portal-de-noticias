# 📟 Projeto Portal de Notícias

Um portal de notícias dinâmico, onde o usuário pode acessar as últimas novidades organizadas por categorias e tópicos. Este projeto foi desenvolvido com foco no treinamento de CSS Grid.  

---

## 🚀 Funcionalidades  

- 🌐 Exibição de notícias 
- 🔍 Filtros por categorias  
- 🌟 Destaques das principais manchetes  

---

## 🛠️ Tecnologias  

As principais tecnologias utilizadas no projeto são:  

- **Frontend**:  
  - HTML5, CSS3

- **Design**:  
  - Figma 

- **Editor**:  
  - VS Code

## 🧰 Como Rodar o Projeto Localmente  

1. **Clone este repositório:**  
   ```bash
   git clone https://github.com/devmoisessantos/projeto-portal-de-noticias.git  
   cd projeto-portal-de-noticias  
   ```   

2. **Acesse o projeto no navegador:**  
   - Abra: `http://localhost:5000`
